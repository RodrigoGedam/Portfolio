# Portfólio — Rodrigo Gedam

Portfólio pessoal de Rodrigo Gedam, Desenvolvedor Front-end com experiência prática em soluções full-stack.

## Tecnologias

- React, TypeScript e Vite
- Tailwind CSS
- i18next para português e inglês

## Executar localmente

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```
